2.1 Файл db.py
python
import pymysql  # или mysql.connector

DB_CONFIG = {
    "host": "127.0.0.1",
    "port": 3306,
    "user": "root",
    "password": "",
    "database": "exam_db",
    "charset": "utf8",
}

def get_connection():
    return pymysql.connect(**DB_CONFIG)

3.4 Ключевые SQL-запросы (адаптировать)
Товары:

sql
SELECT p.*, c.category_name, m.manufacturer_name, s.supplier_name
FROM products p
JOIN categories c ON p.category_id = c.category_id
JOIN manufacturers m ON p.manufacturer_id = m.manufacturer_id
JOIN suppliers s ON p.supplier_id = s.supplier_id
Пользователи (если таблицы разделены):

sql
SELECT u.user_id, uf.fio, ur.role
FROM users u
JOIN user_fio uf ON u.fio_id = uf.fio_id
JOIN user_roles ur ON u.role_id = ur.role_id
WHERE u.login = %s AND u.password = %s
Заказы:

sql
SELECT o.*, s.status_name, p.address
FROM orders o
JOIN order_status s ON o.status_id = s.status_id
JOIN pvz p ON o.pvz_id = p.pvz_id
